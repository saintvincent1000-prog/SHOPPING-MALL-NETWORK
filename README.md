# SHOPPING-MALL-NETWORK

## OVERVIEW
THIS PROJECT DEMONSTRATES THE DESIGN AND IMPLEMENTATION OF A SHOPPING MALL NETWORK USING CISCO PACKET TRACER.

## TECHNOLOGIES USED

- VLANS
- TRUNKING
- DHCP
- INTER-VLAN ROUTING
- PORT ADDRESS TRANSLATION
- ACCESS-LIST
- WIRELESS
- SSH
- PORT-SECURITY
- STATIC ROUTE
- DNS

## DEVICES USED

- 2 ACCESS SWITCHES
- 1 MULTILAYER SWITCH
- 2 ROUTERS
- 1 SERVER
- 1 ACCESS POINT
- 1 PRINTER
- 11 COMPUTERS
- 2 LAPTOPS
- 2 SMARTPHONES
- 2 TABLET DEVICES

## VLAN STRUCTURE

| VLAN | Department |
|------|------------|
| 10 | POS |
| 20 | SELF CHECKOUT |
| 30 | BACK OFFICE |
| 40 | GUEST WIFI |
| 50 | PRINTERS |
| 99 | MANAGEMENT |
| 999 | UNUSED PORTS |

## KEY FEATURES

- 5 PRODUCTION VLAN SEPARATING POS,SELF CHECKOUT,BACK OFFICE,GUEST WIFI,PRINTERS
- INTER-VLAN ROUTING
- DHCP FOR ADDRESS ASSIGMENT
- DNS TO RESOLVE THE SERVERS HOSTNAME
- SSH FOR SECURE DEVICE REMOTE MANAGEMENT
- WIRELESS NETWORK
- PORT ADDRESS TRANSLATION FOR LAN DEVICES ACCESS TO THE INTERNET
- PORT SECURITY TO DISABLE UNAUTHORIZED DEVICES ON THE LAN

## SKILLS DEMONSTRATED

 ## CHALLENGES AND TROUBLESHOOTING

- DURING THE COURSE OF THIS WORK, I FACED SEVERAL CONNECTIVITY AND COMMUNICATION SETBACKS, I HAD TO THINK CRITICALLY AND FOLLOW THE RIGHT STEPS TO IDENTIFY THE ROOT CAUSE OF THE ISSUES AND FIX IT UP.

CHALLENGE 1. GUEST WIFI USERS COULD NOT CONNECT TO THE INTERNET ( 203.0.113.1 AND 203.0.113.2 )  PINGS FROM GUEST WIFI USERS TO THE INTERNET WERE RETURNED WITH ( REQUEST TIMED OUT ).

PROBLEM
- GUEST WIFI VLAN WASN'T ALLOWED ON ITS ACCESS SWITCH TRUNK LINK CONNECTED TO THE LAYER 3 SWITCH PERFORMING INTER-VLAN ROUTING

SOLUTION
- I FIXED IT BY GOING INTO THE ACCESS SWITCH TRUNK LINK CONNECTING THE MULTILAYER SWITCH AND ALLOWED GUEST WIFI VLAN

  CHALLENGE 2. PRINTERS COULD NOT CONNECT TO THE NETWORK, THEY COULDN'T OBTAIN IP ADDRESSES VIA DHCP AND EVEN IF ADDRESSES WAS MANUALLY CONFIGURED, THEY COULD NOT CONNECT WITH DEVICES ON OTHER VLANS.

PROBLEM
  - THE INTERFACE OF THE PRINTER WAS NOT ENABLED ON THE MULTILAYER SWITCH PERFORMING INTER-VLAN ROUTING
 
  SOLUTION
  - I WENT INTO THE LAYER 3 SWITCH PERFORMING ROUTING AND ENABLED THE PRINTER'S VLAN INTERFACE
 
    CHALLENGE 3. ALL NODES ON THE NETWORK COULDN'T ACCESS THE PAYMENT SERVER (192.51.100.2) AND THE INTERNET (203.0.113.1 & 203.0.113.2) BUT COMMUNICATIONS BETWEEN INTERNAL NETWORKS, MULTILAYER SWITCH AND EDGE ROUTER WAS SUCCESSFUL. HOWEVER, THEY COULD NOT GO BEYOND THE EDGE ROUTER.

PROBLEM 
- THE EDGE ROUTER'S POINT T0 POINT INTERFACE CONNECTING WITH THE ISP ROUTER WAS USING A WRONG IP ADDRESS.

SOLUTION
- I REASSIGNED AND CORRECTED THE IP ADDRESS OF THE INTERFACE CONNECTING THE EDGE ROUTER TO THE ISP ROUTER, FROM (203.0.118.2 TO 203.0.113.2).

 SOLUTION
 - 
SHOPPING MALL NETWORK BUILT WITH CISCO PACKET TRACER FEATURING VLANs, DHCP, INTER VLAN ROUTING, PAT, ACCESS-LIST, WIFI, SSH, PORT-SECURITY, STATIC ROUTE.
